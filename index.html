Sincronização com GitHub

Não configurado — dados salvos apenas neste navegador

Leitura (ver o cronograma) funciona sem token, para qualquer pessoa, se o repositório for público — os dados vêm direto de raw.githubusercontent.com.
Escrita (salvar alterações) exige um token pessoal do GitHub com permissão de conteúdo neste repositório. Use um fine-grained token restrito só a este repositório. O token fica salvo apenas no armazenamento local deste navegador — nunca é enviado a nenhum lugar além da própria API do GitHub. Qualquer pessoa com esse token pode editar o repositório, então trate-o como uma senha e não o compartilhe publicamente.

A sincronização é manual — nada é enviado ao GitHub sozinho. Depois de editar, clique em "Salvar no GitHub" (ou apenas "Salvar no navegador" se ainda não quiser publicar). Se você tentar fechar ou sair da página com alterações do GitHub ainda não enviadas, o navegador mostra um aviso antes de deixar você sair.
